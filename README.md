# mateuszdombrowski.com

Strona usługowa Mateusza Dombrowskiego: BaseLinker, automatyzacje i strony dla sklepów.

- **Kod strony:** folder `site/`. Czysty HTML, CSS i JavaScript, bez budowania. Animacje: GSAP i Lenis, trzymane lokalnie w `site/assets/js/vendor/`.
- **Publikacja:** GitHub Actions (`.github/workflows/deploy.yml`) wysyła folder `site/` na GitHub Pages po każdym pushu na `main`.
- **Poprzednia wersja** (React, Vite, three.js) jest zapisana pod tagiem `stara-strona-2026-10`.
